# Banka marka varlıkları

`ziraatdinamik.png`, kullanıcının sağladığı orijinal Ziraat Dinamik görselidir.
Dosyanın pikselleri değiştirilmez; arayüz çizim sırasında boş kenarlarını
kırpar ve diğer banka logolarıyla aynı sınırlı alanda oranını koruyarak gösterir.
Logo çevrimdışı pakete dahildir. Marka hakları ilgili bankaya aittir.

Kurumun marka görselleri: https://www.ziraatdinamik.com.tr/tr/hakkimizda/basin-odasi/bankamiz-gorselleri
